# Mantenimiento de GraphicView

Antes de modificar esta aplicación, leer `CONTEXTO-GRAPHICVIEW.md`. Conservar los contratos de datos y funciones allí descritos. Al terminar cada cambio, actualizar ese archivo con alcance, pruebas realmente ejecutadas, versión y estado de publicación. El usuario autorizó almacenamiento únicamente en el SSD; no crear cachés ni instalaciones en el disco interno. La versión original de Sites no se modifica.
